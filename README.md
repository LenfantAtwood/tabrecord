# TabRecord

TabRecord 是一个面向吉他演奏者的实时 TAB 录制与编辑工具。它从麦克风获取演奏音频，可选地结合摄像头中的左手/指板位置先验，持续生成可修订的音符事件、六线谱和 MIDI，并将确认后的乐谱导出为 Guitar Pro 文件。

> 当前状态：产品与技术方案已建档，尚未进入功能实现。首个里程碑是完成技术可行性验证，而不是承诺“零延迟、零错误”的自动扒谱。

## 产品目标

- 演奏时尽快看到“暂定”TAB，停止或继续演奏时自动校正最近若干拍。
- 支持 Guitar Pro 文件导入、实时渲染、人工纠错与导出。
- 使用乐器可演奏性与可选手势信息，解决同一音高对应多个弦品位置的歧义。
- 保留可复现的原始事件、模型置信度和人工修改，不把渲染格式当作唯一数据源。

## 首版边界

首版优先支持标准六弦吉他、标准/自定义调弦、单把吉他输入，以及近实时的本地会话。目标延迟为“可用于练习和创作记录”的 1–3 秒级，而不是舞台级小于 10 ms 的监听效果。

首版输出：

- 屏幕中的标准谱 + TAB 实时预览；
- MIDI 文件；
- Guitar Pro 7 `.gp` 文件；
- TabRecord 内部会话文件，用于无损恢复和继续编辑。

首版不承诺完整歌曲中的人声/鼓/贝斯分离、重失真下的完美复音转录、Guitar Pro 8 全特性回写或无人工校对的出版级乐谱。

## 关键技术选择

- **alphaTab**：Guitar Pro 导入、TAB/标准谱渲染、播放，以及 GP7 导出。项目中曾提到的 “audioTab” 很可能指它。
- **内部事件模型**：音符、节拍、弦品、技法、置信度、来源和修订历史的唯一事实来源。
- **两阶段转录**：最近窗口为 `provisional`（可修订），跨过确认线后变成 `committed`（默认不再被模型改写）。
- **音频基线**：先离线评估 Basic Pitch / TabCNN 类方法，再通过重叠窗口做流式适配；Basic Pitch 本身不是原生实时系统。
- **弦品解码**：先用调弦、跨度、换把、同弦连续性等可演奏约束，再加入摄像头手势概率作为软先验。

```text

fixtures/                 小型、可再分发的黄金测试样例说明

```

## 建议的第一周

1. 用 3 个合法可再分发的短音频样例建立离线基线。
2. 验证 alphaTab 的 GP3–8 导入、局部重渲染和 GP7 往返导出。
3. 定义并冻结 `NoteEvent`、`TabPosition`、`Revision`、`ScoreSnapshot` 的 v0 JSON Schema。
4. 做一个 30 秒会话切片：麦克风 → 音频环形缓冲 → 暂定音符 → 静态 TAB。
5. 记录端到端延迟、音符 F1、弦品准确率和导出往返差异，决定是否进入 MVP。

TabRecord 自身的许可证尚未由仓库所有者决定。依赖项仍遵循各自许可证；尤其 alphaTab 为 MPL-2.0。发布或接收外部贡献前必须完成 `TAB-008`。
