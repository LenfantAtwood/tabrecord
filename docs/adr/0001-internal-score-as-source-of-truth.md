# ADR-0001：内部乐谱事件模型是唯一事实来源

- 状态：Proposed
- 日期：2026-08-27

## 背景

MIDI 不保存完整弦品与修订信息，GP8 是交换格式，alphaTab 的 `Score` 面向输入、渲染和播放。实时转录还需要暂定事件、撤回、置信度、来源、人工锁定和原始时间。

## 决策

TabRecord 使用版本化的内部事件日志和规范乐谱快照作为唯一事实来源。MIDI、GP8 和 alphaTab `Score` 都由适配器派生。GP8 输入先转换为内部模型，写回前从内部模型重新生成。

## 后果

- 可以保留实时修订和人工编辑历史；
- 渲染器、模型和文件库可替换；
- 必须维护 schema 迁移与适配器黄金测试；
- 无法用“直接修改 alphaTab 对象”快速省掉核心建模工作。
