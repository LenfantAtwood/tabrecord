# ADR-0004：受限的本地单音 audio → TAB 实验切片

- 状态：Accepted（仅适用于本实验切片）
- 日期：2026-09-22
- 关联：TAB-101、TAB-407；不代表完成复音转录或完整 MVP

## 决策

上传音频与麦克风共享浏览器本地单音分析路径。用 Worker 中的 YIN 基线得到音符候选，不上传媒体、不下载模型权重。限长 120 秒，只支持单把吉他的逐音旋律；和弦、伴奏、失真、泛音和滑音都可能误判。能力需要用户主动开启。

版本 1 `TabScore` 是本切片渲染、MIDI 与会话保存的唯一事实来源。JSON Schema 位于 `apps/web/src/features/audio/tabSession.schema.json`，导入还会执行时间、调弦、弦品、单音重叠等语义校验；不接受未知版本。契约先局限于功能目录，未来稳定后迁往 `packages/contracts`，不宣称已完成通用事件日志。

- 原始 `startSeconds`/`endSeconds` 均为相对音频起点的秒数，原样保留。
- 固定 4/4、用户指定 40–240 BPM，480 PPQ，量化到十六分音符（120 ticks）。量化不能反推或覆盖原始秒时间；碰撞依时间顺序移到下个可用格，音符至少一个格。
- 标准调弦 MIDI `[64, 59, 55, 50, 45, 40]`，弦 1 是高 E、弦 6 是低 E，0–24 品、capo=0。合法位置必须满足 `midi = tuning[string - 1] + fret`。
- DP 对整条单音序列选择弦品；代价包括低把位、换把和跨弦。候选保留供手动切换。这只是可解释先验，不能从音频恢复真实演奏弦品。
- 每个音符保留音高、力度、置信度、来源、状态和人工弦品修订。弦品操作产生新快照并锁定该音符；保存会话保留修改历史。不允许继续分析覆盖用户正在编辑的快照。
- 录制中的整段有限预览都是 provisional；停止并完成最终分析后才 committed。预览会重算，尚未实现 ADR-0002 的滚动确认线、增量操作协议及 30 分钟采集。UI 必须明确区分预览与最终结果。
- alphaTex 是纯派生的渲染适配格式。补全休止、拆分跨小节时值并以延音线连接，避免重复触发。alphaTab 的动态级别会近似原始 MIDI 力度；MIDI 保留确切的 1–127 力度值。
- 导出 Standard MIDI File Type 1：480 PPQ，独立 tempo/拍号轨与单音吉他轨；note-on/off 使用快照量化 ticks，不从原始音频另算。跨小节延音只导出一个 note-on/off。MIDI 不保存弦品，恢复使用版本化 JSON 会话。

## 验证与边界

用代码生成合成音频测试识别，避免提交媒体。谱面适配测试覆盖标准音高与弦品硬约束、休止、量化碰撞、跨小节延音、会话校验、人工修改恢复以及 MIDI 二进制解码后的时间/力度/拍号。alphaTex 由锁定版本 alphaTab 解析，检查其音高和延音语义。

这套测试证明通路与确定性契约，不证明真实吉他准确率、目标设备延迟或正式实时 SLA。Basic Pitch/TabCNN 对比、固定真实吉他评测集、p50/p95 延迟仍是后续验证。暂不支持复音、自动速度、弯音、GP8 写回、原始媒体会话打包及完整撤销重做。

alphaTex 依据上游 [文档结构](https://alphatab.net/docs/alphatex/document-structure) 与 [延音语法](https://alphatab.net/docs/alphatex/note-properties)；升级 alphaTab 时须重新跑解析测试。
